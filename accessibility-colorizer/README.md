# ChromaAccess — Accessibility Colorizer

A full-stack mobile tool that makes paintings and visual art accessible to people with color vision deficiency (CVD).

## Modes

- **Museum Mode** — people with CVD photograph or upload an artwork and receive a corrected version that compensates for their specific color deficiency (deuteranopia, protanopia, or tritanopia), with adjustable severity.
- **Designer Mode** — artists upload a painting and receive AI-powered accessibility feedback: an overall accessibility score, affected population estimate, per-condition issue breakdowns with affected color swatches, and hex-code replacement suggestions generated by Claude Vision.

## Architecture

The React Native (Expo) mobile app communicates with a FastAPI Python backend. The backend runs CVD simulation and correction using perceptual color math (LMS colorspace, daltonize-style matrices), extracts dominant colors via k-means clustering in LAB colorspace, computes WCAG 2.1 contrast ratios for every color pair, and sends the image plus color analysis data to Claude Opus Vision to produce structured JSON accessibility recommendations. All image processing runs in memory — no persistent storage required.

## Prerequisites

- Node.js 18+
- Python 3.11+
- Expo CLI (`npm install -g expo-cli`)
- An Anthropic API key (for Designer Mode analysis)

## Setup

### Backend

```bash
cd accessibility-colorizer/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env and set ANTHROPIC_API_KEY=your_key_here
```

### Mobile app

```bash
cd accessibility-colorizer/apps/mobile
npm install
cp .env.example .env  # or edit .env directly
# Set EXPO_PUBLIC_API_URL to your backend address (default: http://localhost:8000)
```

## Run locally

**Terminal 1 — backend:**
```bash
cd accessibility-colorizer/backend
source .venv/bin/activate
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**Terminal 2 — mobile:**
```bash
cd accessibility-colorizer/apps/mobile
npx expo start
```

Scan the QR code with Expo Go on your device, or press `i` for iOS simulator / `a` for Android emulator.

## Environment variables

| Variable | Where | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | `backend/.env` | Anthropic API key for Claude Vision |
| `MAX_IMAGE_SIZE_MB` | `backend/.env` | Max upload size (default: 10) |
| `ALLOWED_ORIGINS` | `backend/.env` | CORS origins, comma-separated (default: `*`) |
| `EXPO_PUBLIC_API_URL` | `apps/mobile/.env` | Backend base URL (default: `http://localhost:8000`) |

## API endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/health` | Health check |
| `POST` | `/upload` | Upload image (JPEG/PNG/WEBP, max 10 MB) |
| `POST` | `/simulate` | Simulate CVD perception |
| `POST` | `/correct` | Apply daltonize correction |
| `POST` | `/analyze` | Full Claude Vision accessibility analysis |

## Docker (backend only)

```bash
cd accessibility-colorizer/backend
docker build -t chroma-access-api .
docker run -p 8000:8000 -e ANTHROPIC_API_KEY=your_key chroma-access-api
```
